Tracks pi **1.7.0** (upstream pin `2126569de`).

## Highlights
- Image output is priced at the image rate: image tokens no longer bill at the text rate, so generated images cost what the provider charges
- Ant Ling uses DeepSeek's thinking on/off switch, with `Ling-3.1-flash` as its default model; a models.json that still says `"ant-ling"` keeps working
- Model catalog refreshed to pi 1.7.0: 1,701 models across 43 providers, with Ling 3.x, GPT-6 Healthcare, Claude 5.5 in Canada on Bedrock and Kimi K3 added
